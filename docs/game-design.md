# 拼字蜂：蜂巢保衛戰 — 遊戲設計計畫書

> 把聽寫練習從「問答題 + 金幣計數器」改造成一款**以打字為武器的塔防 Roguelite**。
> 核心迴圈不變：聽發音 → 打出來 → 比速度與正確率。變的是這個動作在遊戲裡的意義。

---

## 目標平台（設計前提）

**主要：桌機瀏覽器（實體鍵盤）。次要：iPad 橫向。手機不在設計目標內。**

這個前提決定了下面所有版面與數值，不是註腳：

| 影響 | 因為有實體鍵盤與大螢幕 |
|---|---|
| 構圖 | 16:9 全螢幕橫向，畫面高度完整可用，不必為虛擬鍵盤讓位 |
| 操作 | **全鍵盤，不需要滑鼠**。重聽／慢速／例句改成按鍵，手不離鍵盤 |
| 手感 | 連續快速打字才能打出音階節奏感——這在觸控螢幕上做不出來 |
| 演出 | 粒子、視差、後製特效可以開到桌機 GPU 的水準 |

iPad 橫向沿用同一套版面，只是把三個聽力按鍵放回螢幕上（外接鍵盤時同桌機）。
若 iPad 用螢幕鍵盤，可用高度約剩六成——**戰鬥場景維持又寬又扁的構圖就能相容**，不需要第二套版面。

---

## 0. 為什麼要改

現有版本的問題不在畫面，在三件事：

| 問題 | 現況 | 改造後 |
|---|---|---|
| 打字不是動作，只是表單 | 輸入 → 按送出 → 播放獎勵動畫。獎勵發生在打字**之後**，與打字本身無關 | 每按對一個字母就是一次攻擊，敵人當場被擊退 |
| 不會輸 | 只有獎勵沒有風險 | 有血量、會失敗、一場冒險會結束 |
| 每次都一樣 | 每場流程完全相同 → 「又來了」 | 路線、能力三選一、角色，每場都不同 |

**買帽子只改變外觀，買「連對 3 個字進入子彈時間」才會改變你怎麼玩。** 這是整份設計的中心思想。

---

## 1. 三層結構

```
Layer 3  一次冒險 Run        ← 路線選擇、能力三選一、王關（8~12 分鐘）
  └ Layer 2  一場戰鬥 Battle  ← 敵人波次、血量、連擊（1~2 分鐘）
      └ Layer 1  一次輸入      ← 逐字母即時回饋（3~8 秒）
```

Layer 1 決定「爽不爽」，Layer 2 決定「緊不緊張」，Layer 3 決定「會不會膩」。
三層都要做，但**Layer 1 是成敗關鍵**。

---

## 2. Layer 1：一次輸入（最重要）

這一層做對了，整個遊戲就成立；做錯了，後面再華麗都沒用。

### 規格

畫面上不顯示已打的字母文字，改成一條**能量槽**與敵人身上的裂痕。

**每按對一個字母：**
- 蜂針飛出擊中敵人（約 0.1 秒），敵人閃白並後退一小段
- 一片字母碎片飛向蜂巢
- **打擊音音高遞增**：第 1 個字母 C、第 2 個 D、第 3 個 E⋯ 打完一個字剛好是一段上行音階

> 這個音階設計是整個手感的核心。打字遊戲之所以讓人上癮，很大一部分來自「每個按鍵都有回應、而且連起來變成旋律」。

**打完最後一個字母：**
- 敵人爆開成蜂蜜噴濺，畫面輕微頓挫（hit stop，約 80ms）
- 下一隻敵人立刻上前，發音自動播放

**按錯字母：**
- 畫面紅閃 + 震動 + 低沉錯誤音
- 敵人前進一步
- **不清空已打的內容**，那個錯誤字母單純不被接受，繼續打正確的即可（避免小孩挫折到放棄）

### 不能省的細節

- **沒有送出鈕**：最後一個字母打完當下就結算
- **壓力是看得見的**：是敵人在逼近，不是一條抽象的進度條
- **重聽有代價**：見下表。現在「再聽一次」免費，所以完全沒有張力

| 動作 | 按鍵 | 代價（敵人前進相當於幾秒的距離） |
|---|---|---|
| 再聽一次 | `↑` | 1.5 秒 |
| 慢速重聽 | `↓` | 2.5 秒 |
| 聽例句 | `→` | 2.0 秒 |

### 鍵盤配置（桌機）

方向鍵不與任何字母衝突，而且就在右手邊、緊鄰 Enter，小孩不用學就會按。

| 鍵 | 功能 |
|---|---|
| A~Z | 拼字（就是攻擊） |
| `↑` `↓` `→` | 再聽／慢速／例句 |
| `Backspace` | 刪掉最後一個字母（不扣血、不讓敵人前進） |
| `Esc` | 暫停 |

**全程不需要滑鼠**，包括地圖選路線與三選一能力（`←` `→` 選、`Enter` 確定）。
輸入焦點永遠鎖在遊戲上，玩家不會「打了半天發現沒打進去」。

## 3. Layer 2：一場戰鬥

### 場景

橫向單線道。左邊是蜂巢（你的基地），右邊是入侵口，敵人由右向左推進。

畫面上**同時有 3~5 隻敵人排隊**（製造視覺壓力），但只有最前面那隻是當前目標——因為聽寫一次只能聽一個字。

桌機 16:9 全螢幕，畫面由下往上分三段：**戰場（約 65%）／能量槽與血量 HUD（約 15%）／敵人隊列與 Combo（約 20%）**，
整場戰鬥不捲動、不切換視角，眼睛只需要在戰場中央來回。

> 構圖仍維持**又寬又扁的橫向長條**——不是為了手機，而是因為敵人是橫向逼近的，
> 而且這樣同一套版面在 iPad 螢幕鍵盤彈出時（可用高度剩約六成）不用改就能用。

### 數值

| 項目 | 數值 |
|---|---|
| 起始血量 | 3 顆蜂蜜罐 |
| 敵人橫越畫面時間 | **3 秒（聽的時間）＋ 每個字母 0.6 秒**（見下方難度） |
| 打錯一個字母 | 敵人前進 1 秒的距離 |
| 敵人抵達蜂巢 | 扣 1 血，該單字重新排進本場隊列 |
| 血量歸零 | 本次冒險結束 |

時間**跟著單字長度走**，不是固定值。`cat` 給 4.8 秒、`environment` 給 9.6 秒——
否則短字太鬆、長字必死，小孩會學到「看到長字就放棄」。

**難度（可設定，也會自動微調）**

| 模式 | 公式 | `account`（7 字母） | 適用 |
|---|---|---|---|
| 輕鬆 | 3 + 0.9×字母 | 9.3 秒 | 剛開始、打字還不熟 |
| 標準 | 3 + 0.6×字母 | 7.2 秒 | 預設 |
| 挑戰 | 3 + 0.4×字母 | 5.8 秒 | 熟練之後 |

**第一次開始遊戲時先校準**：用 3 個已經很熟的字量他的實際按鍵間隔，直接建議起始難度，不要讓他第一場就被打爛。

自動微調：連續 3 場正確率 > 90% 就建議升一階；連續 2 場血量歸零就建議降一階（詢問而非強制，讓小孩自己選）。

### 連擊 Combo

連續打對且不失誤時累積，打錯歸零。

| Combo | 效果 |
|---|---|
| 5 | **蜂群衝刺**：3 秒內敵人減速 50% |
| 10 | 下一個單字自動擊殺 |
| 15 | **狂蜂狀態**：5 秒內所有字自動擊殺 |

## 4. Layer 3：一次冒險 Run

### 結構

一個 Run = 一個 Part（25 個單字），約 8~12 分鐘。

地圖分 5 層，每層有 2~3 個節點可選，玩家**自己選路線**：

```
        ┌─ 戰鬥 ─┐     ┌─ 精英 ─┐     ┌─ 戰鬥 ─┐
  起點 ─┤        ├─選擇─┤        ├─選擇─┤        ├─ 王關
        └─ 商店 ─┘     └─ 寶箱 ─┘     └─ 商店 ─┘
```

| 節點 | 單字數 | 內容 |
|---|---|---|
| 一般戰鬥 | 5 | 標準敵人 |
| 精英戰鬥 | 6 | 敵人速度 +25%，但獎勵是**稀有能力** |
| 商店 | 0 | 用本場蜂蜜買能力或補血 |
| 寶箱 | 0 | 隨機獲得一個能力，或補 1 血 |
| 王關 | 5 | 見下方 |

**路線是真正的取捨**：全部走戰鬥＝練滿 25 字、蜂蜜最多；多走商店寶箱＝能力更強但練得少。走完全戰鬥路線剛好練完一整個 Part。

每通過一個節點，**三選一**拿一個能力。

### 王關

- 出題優先選**這個 Part 裡最常打錯的 5 個字**（直接接現有的 Leitner 資料）
- 每個字**只唸一次**（除非有「回音水晶」能力）
- 王有護盾：每個單字要**連續打對兩次**才能擊破
- 打倒後：本 Part 標記為「已征服」，解鎖該 Part 的獎盃

---

## 5. 能力（三選一）

讓每場不同的關鍵。玩家每場約拿到 4~5 個，從 15+ 個池子裡抽 3 個選 1。

### 攻擊型
| 名稱 | 效果 |
|---|---|
| 蜂針強化 | 每個正確字母的擊退 +30% |
| 首字重擊 | 每個單字第一個字母打對，敵人直接後退一半 |
| 長字獵手 | 7 個字母以上的單字，蜂蜜獎勵加倍 |

### 防禦型
| 名稱 | 效果 |
|---|---|
| 蜂蠟護盾 | 每場戰鬥開始時獲得 1 點臨時護盾 |
| 二次機會 | 每場戰鬥第一次漏字不扣血 |
| 蜂巢加固 | 血量上限 +2 |

### 聽力型
| 名稱 | 效果 |
|---|---|
| 回音水晶 | 重聽不再讓敵人前進 |
| 慢速大師 | 慢速重聽的代價減半 |
| 例句直覺 | 每個字可以免費聽一次例句 |

### 連擊型
| 名稱 | 效果 |
|---|---|
| 蜜糖節奏 | Combo 門檻從 5 降到 3 |
| 連鎖反應 | Combo 每 +1，蜂蜜獲得 +5% |

### 風險型（高風險高報酬）
| 名稱 | 效果 |
|---|---|
| 玻璃蜂針 | 傷害 ×2，但血量上限變成 1 |
| 盲打之證 | 關閉螢幕上的能量槽提示，蜂蜜 ×2 |
| 一發入魂 | 每個字只能聽一次，但擊殺獎勵 ×3 |

> 風險型能力是讓小孩覺得自己「很會玩」的來源，也是每場差異最大的部分。一定要有。

---

## 6. 跨場進度（Meta）

### 蜂蜜
Run 結束時（不論勝敗）保留一部分蜂蜜，用來永久解鎖。**失敗也有收穫**，這點很重要。

### 角色（改變規則，不只是外觀）

| 角色 | 特性 |
|---|---|
| 工蜂（預設） | 平衡 |
| 偵察蜂 | 敵人速度 −20%，但血量只有 2 |
| 兵蜂 | 血量 5，但重聽代價加倍 |
| 蜂后 | 每場多一次三選一，但敵人多 1 隻 |

### 單字圖鑑
每個單字打對 N 次會被「馴服」，收進圖鑑。100 個字全馴服 = 最終成就。
這是給 Minecraft/寶可夢世代的收集要素。

### 現有商店怎麼辦
造型／主題／小遊戲併入 meta 解鎖（用蜂蜜買），不再是獨立分頁。

---

## 7. 學習效果不能被犧牲

遊戲化不能變成「玩得開心但沒學到」。以下是硬性要求：

- 本場漏掉或打錯的字，**在同一場 Run 內重新排隊**（立即複習）
- Run 結束後這些字進入既有的 Leitner 間隔複習佇列
- 王關優先出現該 Part 最弱的字
- 統計完整保留：正確率、平均反應時間、每個字的熟練度、最常錯的字母位置
- 家長可在「我的檔案」看到完整數據（這部分維持現狀）

---

## 8. 美術方向

- **保留蜜蜂主題**，沿用現有吉祥物，但加上戰鬥姿態與受擊動畫
- **敵人要有「對手感」而不是可愛**：入侵蜂巢的甲蟲、黃蜂、蜘蛛，剪影 + 亮色描邊風格，全部原創設計
- **16:9 全螢幕橫向場景**，前景／中景／背景三層視差捲動
- **遊戲畫面沒有導覽列**：遊戲就是遊戲，選單另外走
- 粒子：字母碎片、蜂蜜噴濺、擊殺爆炸、combo 光環——桌機 GPU 撐得住，不必像手機那樣省
- 素材按 1920×1080 設計；iPad 直接等比縮放，不另做一套

## 9. 實作階段

| 階段 | 內容 | 驗證點 |
|---|---|---|
| **1. 核心手感** | 逐字母回饋、音階打擊音、單一敵人逼近與擊退、全鍵盤操作、難度校準 | **給兒子在電腦上玩 5 分鐘** |
| 2. 一場戰鬥 | 多敵人排隊、血量、漏字、Combo、難度 | 一場戰鬥好不好玩 |
| 3. Run 結構 | 地圖、節點、三選一、商店、王關 | 玩第二次還想玩嗎 |
| 4. Meta | 蜂蜜、角色、圖鑑、併入現有商店 | 會想回來嗎 |
| 5. 打磨 | 美術、音效、粒子、轉場 | — |

### ⚠️ 最重要的一句話

**Phase 1 做完就停下來，讓兒子玩五分鐘。**

如果他眼睛沒有亮起來，就不要往下做。核心手感對不對，五分鐘就看得出來，不需要等到整套做完。這是整個計畫最便宜的止損點——我們已經在這個專案上花了很多力氣做「完整但不好玩」的東西，不要再重複一次。

## 10. 技術決定

**不換平台，繼續用 Phaser。** 理由：

- 手感問題來自設計，不是引擎。Phaser 做 2D 動作遊戲綽綽有餘
- 這是唯一我能**自己跑起來、截圖、量測、驗證**的選項（這幾天抓到的 bug 幾乎都靠這個能力）
- 你零設定成本，打開瀏覽器就能玩，不用裝東西
- **桌機是瀏覽器最強的地方**：鍵盤事件精準、GPU 充足、Fullscreen API 可用。改以桌機為主之後，用網頁做這件事比之前更划算，不是妥協

桌機相關的實作要點：進入戰鬥時呼叫 Fullscreen API、鍵盤事件直接綁在 window 上（不經 `<input>`，避免輸入法與焦點問題）、
按鍵到畫面回饋的延遲要壓在一個影格內（16ms）——這是「打起來爽不爽」的實際來源。

### 沿用現有系統
單字庫（100 字）、Leitner 複習、暱稱+PIN 登入、進度統計、真人錄音 + TTS、本地優先同步、離線佇列。

### 需要改寫
- 練習頁 → 全螢幕遊戲場景
- 商店 → 併入 meta 解鎖
- Phaser 場景架構：從「一隻會跳的蜜蜂」變成真正的多場景遊戲（戰鬥場景、地圖場景、結算場景）

## 11. 已知風險

| 風險 | 說明 | 對策 |
|---|---|---|
| **中文輸入法** | 電腦停在注音模式時，按字母會跳出選字視窗，遊戲完全不能玩 | 偵測到輸入異常就跳全螢幕提示「請切回英文輸入法」，並在開始前先要求按一個字母確認 |
| 小四生打字速度 | 還在看鍵盤找字母，可能跟不上 | 時間跟著字母數走 + 開場校準 + 三段難度自動微調 |
| iPad 螢幕鍵盤 | 可用高度剩約六成 | 版面本來就是寬扁構圖，等比縮放即可；三個聽力鍵在 iPad 上顯示為螢幕按鈕 |
| 挫折感 | 連續失敗會放棄 | 二次機會、失敗也有蜂蜜、難度自動建議下調 |
| 打字練習變成反射練習 | 為求快而不思考拼字 | 王關只唸一次、長字加倍獎勵，鼓勵確實聽清楚 |
| 做完還是不好玩 | 最大的風險 | **Phase 1 止損點** |
