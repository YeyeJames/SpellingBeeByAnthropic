## 既有測試已經涵蓋的
- 伺服器那一半：買造型、裝備的等級門檻與扣蜂蜜、小遊戲每次付費、重送只扣一次、錢不夠不扣
  （shop-test、gear-test、minigame-test、economy-test）
- 同時買兩件、錢只夠一件：步驟三在真的 MongoDB 上驗過

**缺的**：在真的瀏覽器裡、對真的伺服器，把「買 → 用 → 換頁 → 回來」走一遍。
既有的主題測試（theme-test）的伺服器回應是**假造的**。步驟一 G2 擔心的就是這種情況：假回應會把真的錯藏起來。這次就找到一個。

## 結果

| 編號 | 情境 | 結果 |
|---|---|---|
| R1 | 買太陽眼鏡 → 換頁 → 回商店 | ✅ 顯示已擁有 |
| **R3** | **買主題、套用 → 換頁** | ❌ **伺服器根本沒存**：商店那一頁看起來換了，換一頁就變回預設（詳見下面） |
| R2 | 穿上太陽眼鏡 → 個人檔案 | ❌ 一打開看不到；要再換一次頁才看得到 |
| R5 | 個人檔案存音量 → 重新整理 | ❌ 伺服器存了 0.2，滑桿顯示舊的 0.5；要再重新整理一次才對 |
| R6 | 導覽列按靜音 → 換頁 | ❌ **換一頁聲音又回來了**；伺服器其實有存 |
| R4 | 買不成（伺服器說錢不夠） | ✅ 退錢、講原因、按鈕變回「購買」 |
| — | 裝備商店（蜂蜜、等級門檻） | ✅ 每次都跟伺服器拿，不會舊 |

### R3（P1）：買來的主題一次都套用不了
- 商品的 key 是 `theme_space`，套用時前端送的（也是伺服器存的）是 `space`
- 伺服器檢查「有沒有買」時，拿 `space` 去擁有清單裡找，而清單裡存的是 `theme_space`，所以**永遠找不到**，每一次都回「你還沒有解鎖這個造型」
- 商店頁：背景同步把這個拒絕**默默丟掉**，畫面照樣顯示換好了
- 個人檔案頁：錯誤被一行「理論上不會失敗」的註解吞掉，按下去沒有任何反應
- 孩子存 2000 金幣買主題，換一頁就變回預設，而且沒有任何說明

### R2、R5、R6（P2）：換一頁就「舊一格」
每一頁一打開，是先用本機存的「現在是誰」把畫面畫出來，再在背景跟伺服器確認。商店、個人檔案、靜音改了東西之後，只有**金幣**會寫回那一份，主題、配件、音量、靜音都沒有。所以下一頁一打開是舊的，要再換一次頁才對。
其中**靜音**最明顯：按了靜音，換一頁就又有聲音。

## 修正（家長已同意「步驟六現在開始」，逐筆說明後才推）

### 6-A：主題的兩種寫法都認（`facb33c`）
- 伺服器檢查「有沒有買」時，`space` 和 `theme_space` 都算
- 動到 `server/routes/users.js` 一處。**風險：低**

### 6-B：改了什麼就寫回本機（`28451a2`）
- 商店：買東西、換主題、穿脫配件之後，寫回「現在是誰」；伺服器回來的結果也寫回
- 換裝的結果本來沒有人聽：現在伺服器不收就講出來（「沒有換成功：…」），並回到伺服器的狀態
- 買不成時，把伺服器的金幣數拿回來。這一頁以為的金幣如果跟伺服器不一樣，本來會一直顯示錯的數字，他會一直按、一直被拒絕
- 個人檔案：換主題、存音量之後寫回；換主題失敗會講出來，不再吞掉
- 導覽列靜音：寫回，換一頁還是靜音
- **風險：低**。只動畫面與本機快取，不動伺服器的資料

### 驗證
- 新測試 `shop-e2e-test.mjs`：6 段、20 項，連跑 3 次通過
  - 買主題並套用、個人檔案來回切主題、穿配件後看個人檔案、存音量後重新整理、靜音後換頁
  - 錢不夠（退錢、講原因、金幣照伺服器）、換裝被拒絕（講出來、伺服器不變）
- 舊版程式：第一項就失敗（伺服器存的主題是 `sports`），接著卡住跑不下去
